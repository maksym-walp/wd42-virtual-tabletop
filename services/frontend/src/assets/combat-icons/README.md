# Іконки колонок бойової сцени

Покладіть сюди файл із назвою, що збігається з ключем колонки (`png` або `svg`):

- `name.svg` — Ім'я
- `passive_defense.svg` — Пасивний захист
- `active_defense.svg` — Активний захист
- `health.svg` — Здоров'я
- `initiative.svg` — Ініціатива
- `notes.svg` — Примітки
- `description.svg` — Опис

Файли підхоплюються автоматично (`import.meta.glob` у `CampaignCombat.jsx`) — правок коду не потрібно.
Поки файла немає, показується вбудована іконка-заглушка (Lucide або власний SVG).
