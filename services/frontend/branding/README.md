# Логотип

Постав сюди файл **`logo.png`** — квадратний, бажано ≥1024×1024, з прозорим
фоном (PNG з альфа-каналом). Це єдиний вихідний файл: усе інше (іконка
навігаційної панелі, фавікон, іконка на робочому столі/у мобільному "додати
на головний екран" тощо) генерується з нього.

Після заміни `branding/logo.png` запусти з `services/frontend`:

```bash
npm run icons
```

(або через Docker, без локального Node.js: `docker compose run --rm frontend npm run icons`)

Скрипт (`scripts/generate-icons.js`) перезапише в `public/`:

- `logo.png` — сам логотип (пропорції збережені, без квадратних відступів),
  для показу поруч з написом "Walp" у навігаційній панелі (`Navbar.jsx`).
- `favicon.ico` — іконка вкладки браузера (справжній багаторозмірний ICO: 16/32/48).
- `apple-touch-icon.png` (180×180) — іконка при "Додати на головний екран" в iOS.
- `pwa-192x192.png`, `pwa-512x512.png` — іконки PWA-маніфесту (`vite.config.mjs`).
- `maskable-icon-512x512.png` (512×512) — та сама іконка, але вписана в
  безпечну зону з відступом ~20% на суцільному тлі: Android/Chrome можуть
  обрізати іконку по колу чи заокругленому квадрату, і без цього відступу
  краї логотипу будуть обрізані. Фон — `background_color` з маніфесту (`#f4efe4`).

Доки `branding/logo.png` не завантажено (або скрипт не запущено), навбар
просто показує напис "Walp" без картинки — зображення не зламане, його
там немає, це очікувано.
