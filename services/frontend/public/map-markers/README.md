# Типи міток мапи (marker types)

Тут ви самі керуєте типами локацій, їхніми **рівнями** та **іконками** — без правок коду.

## Файли
- `types.json` — список типів. Редагуєте цей файл.
- `icons/` — сюди кладете зображення іконок (PNG/SVG/WebP). Прозорий фон, бажано квадратні ~64×64.

Після зміни файлів достатньо **оновити сторінку** (у dev). У production — перебілдити фронтенд або оновити ці файли в роздачі.

## Формат `types.json`
```json
{
  "defaultLevel": 4,
  "types": [
    { "key": "capital", "label": "Столиця", "level": 4, "emoji": "👑", "icon": "icons/capital.png" },
    { "key": "village", "label": "Село",    "level": 1, "emoji": "🏡", "icon": "" }
  ]
}
```

Поля типу:
- **key** — унікальний ідентифікатор (латиницею, до 50 символів). Саме він зберігається в БД у полі `type` локації. Не змінюйте key наявних типів, інакше старі локації «загублять» тип.
- **label** — підпис, який бачить користувач.
- **level** — 1..4, керує видимістю за масштабом (див. нижче).
- **icon** — шлях до зображення відносно цієї теки (напр. `icons/city.png`). Якщо порожньо (`""`) — показується `emoji`.
- **emoji** — запасна іконка, поки не додали зображення.

## Рівні та видимість (по 25%)
Діапазон зуму мапи ділиться на 4 чверті. Мітка зʼявляється, коли масштаб досягає її порога:

| Рівень | Видима від | Сенс |
|--------|-----------|------|
| **4** (найвищий) | 0% (завжди) | великі обʼєкти — столиці, регіони |
| **3** | 25% | міста, орієнтири |
| **2** | 50% | містечка, руїни |
| **1** (найнижчий) | 75% (значне приближення) | села, дрібні локації |

`defaultLevel` застосовується до типів без вказаного рівня та до локацій, тип яких відсутній у цьому файлі.
